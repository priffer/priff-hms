ระบบเตรียม SQL Views สรุปข้อมูลไว้ให้แล้ว 5 views พร้อม Postgres role อ่านอย่างเดียว (powerbi_readonly) แยกจาก service_role key เพื่อความปลอดภัย

  1. เปิด Power BI Desktop → Get Data → เลือก PostgreSQL database
  2. กรอก Server: db.hcyibcqojsyldiyzperr.supabase.co, Database: postgres (Port 5432)
  3. Username: powerbi_readonly — รหัสผ่านขอจากผู้ดูแลระบบฐานข้อมูล (ตั้งแยกไว้นอกไฟล์โค้ด ไม่ hardcode)
  4. เลือกตารางที่เป็น views: v_attendance_daily_summary, v_ot_summary_daily, v_attendance_absence_summary, v_site_headcount_daily, v_turnover_summary
  5. ตั้งค่า Scheduled Refresh บน Power BI Service เพื่อให้จอใหญ่อัปเดตอัตโนมัติ

Role นี้เห็นเฉพาะ 5 views ด้านบน ไม่สามารถเข้าถึงตารางดิบ (เช่น employees, payroll_lines) หรือแก้ไขข้อมูลใดๆ ได้
