เงินเดือน (Payroll Engine)

เปิด/ปิดรอบเงินเดือน, รันคำนวณ, ตรวจสอบรายละเอียดต่อพนักงาน, อนุมัติ/จ่ายเงิน

ลำดับการทำงานของรอบเงินเดือน

1. สร้างงวด
เลือกงวดให้ตรงกับรอบจ่ายของพนักงาน
2. รันคำนวณ
ระบบสร้าง Run และรายการเงินเดือน
3. ตรวจรายการ
คลิก Run ล่าสุดหรือดูรายละเอียด
4. ส่งตรวจ/อนุมัติ
Payroll ส่ง และ Admin อนุมัติงวด
5. ล็อกหลังจ่าย
ปิดการแก้ไขข้อมูลย้อนหลังของงวด

สร้างรอบใหม่ (รายเดือน/รายวัน), รันคำนวณ, ดูสถานะ run ล่าสุดของแต่ละรอบ

ระบบสร้างวันเริ่ม-สิ้นงวดและวันจ่ายให้อัตโนมัติตามกฎที่ตั้งไว้ ไม่ต้องกรอกวันเอง (กันกรอกผิด) - พนักงานจะถูกจัดเข้ารอบตามที่ตั้งค่า "รอบการจ่าย" ไว้ในแฟ้มประวัติของแต่ละคน

งวด ประเภท วันจ่าย สถานะงวด Run ล่าสุด คลิกเพื่อดูรายการพนักงาน ยอดสุทธิรวม จัดการ
⏳ กำลังโหลดข้อมูล...
พนักงาน เงินเดือนฐาน OT รวม รายได้รวม หักประกันสังคม หักภาษี หักเบิกล่วงหน้า สุทธิ สถานะ จัดการ
กรุณาเลือก payroll run ด้านบน

อัตราที่มีผล ณ ปัจจุบัน (effective_from ล่าสุดที่ไม่เกินวันนี้) — แก้ไขแล้วจะสร้างแถวใหม่ (effective_from = วันนี้) เพื่อรักษาประวัติ ไม่ลบของเดิม

ประเภทอัตรา ค่า เพดานประกันสังคม มีผลตั้งแต่ แก้ไข
