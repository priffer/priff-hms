# KC Clean Trade Component Rules

## Navigation Component

- Must contain only Employee Login and Employer Login
- No extra menu items
- Use clear labels and obvious button contrast

## Hero Component

- Must lead with a single strong headline
- Must include a large search area
- May include a workforce illustration
- Must not feel like a marketing homepage for office users

## Search Component

- Must be visually dominant
- Must be easy to tap on mobile
- Must support fast location-based filtering

## Popular Locations Component

- Show short location labels
- Use card or pill patterns that are easy to tap
- Display counts if available
- Keep location names human-readable

## Featured Jobs Component

- Use cards with strong title hierarchy
- Keep the action buttons obvious
- Use one primary visual rhythm across cards

## Job Card Component

- Title first
- Location second
- Salary third
- Benefits fourth
- Actions at the bottom
- No dense metadata clusters

## Illustration Component

- Use custom vector or simple scene illustrations
- Keep shapes soft and readable
- Use KC Blue and KC Yellow as main accents
- Avoid stock photo treatment

## Benefits Component

- Benefits should support trust, not overwhelm the page
- Keep each benefit short and practical
- Focus on what matters to workforce users
