# KC Clean Trade Layout Rules

## Page Structure

- Hero first
- Search second
- Popular locations third
- Featured jobs fourth
- Employee benefits fifth

## Spatial Rules

- Large whitespace between sections
- Generous padding on mobile and desktop
- Keep content blocks visually separated
- Avoid cramped rows of equal-weight content

## Responsive Rules

- Mobile first
- Single-column by default
- Two-column only when it improves clarity
- No horizontal scroll at any breakpoint
- Avoid layouts that require pinching or zooming

## Content Flow

- Start with the problem: finding work near home
- Then show where to search
- Then show where the jobs are
- Then show why the platform is useful

## Workforce-Specific Layout

- Prioritize practical information over branding decorations
- Keep read order aligned with how workers make decisions
- Make one-thumb navigation possible on mobile
- Keep job cards and filters easy to scan while standing or commuting
