# KC Clean Trade Copywriting

## Voice

- Friendly
- Human
- Direct
- Practical
- Clear for workforce users

## Writing Rules

- Use short sentences
- Use plain Thai whenever possible
- Avoid corporate jargon
- Avoid startup buzzwords
- Avoid marketplace language
- Avoid making the platform sound multi-employer

## Primary Message

> หางานใกล้บ้านคุณ

## Suggested Supporting Phrases

- สมัครง่าย
- เริ่มงานได้เร็ว
- มีรถรับส่งบางพื้นที่
- งานใกล้บ้าน
- ค้นหางานได้ทันที

## Navigation Copy

- เข้าสู่ระบบพนักงาน
- เข้าสู่ระบบนายจ้าง

## Section Copy Guidance

- Hero should tell the user what it is in one glance
- Search should sound helpful, not technical
- Location blocks should feel local and practical
- Featured jobs should feel current and real
- Benefits should sound reassuring, not promotional

## Do Not Use

- Long employer-brand statements
- SaaS-style feature claims
- LinkedIn-style networking copy
- Job marketplace copy
- Corporate recruiting slogans that feel distant from frontline workers
