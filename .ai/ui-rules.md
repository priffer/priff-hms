# KC Clean Trade UI Rules

## Navigation

Keep navigation minimal.

Allowed:

- เข้าสู่ระบบพนักงาน
- เข้าสู่ระบบนายจ้าง

Do not add:

- Blog
- News
- Employer Marketplace
- Corporate Navigation
- About Us

## Layout Rules

- Mobile First
- No Horizontal Scroll
- Large Typography
- Large Search Area
- White Space First
- Card Based Design
- Simple hierarchy
- One-screen clarity

## Interaction Rules

- Primary CTA must be visible quickly
- Search should be usable with one hand on mobile
- Important information must be scannable in a few seconds
- Avoid clutter, hidden complexity, and multi-step discovery on the first screen
- Use obvious button labels
- Keep the first scroll meaningful

## Job Card Priority

1. ตำแหน่งงาน
2. พื้นที่
3. เงินเดือน
4. สวัสดิการ

## Job Card Rules

- Show the position title prominently
- Show location as a fast-scanning element
- Show salary clearly if available
- Show benefits only after the key information
- Keep actions simple and obvious
- Prefer large click targets
- Avoid visual noise inside cards

## Search Rules

- Search must feel like the main action of the page
- Filters must support workforce location-based browsing
- Search UI must stay simple enough for non-office workers
- Search input should be the largest interactive element in the hero

## Visual Rules

- Use KC Blue, KC Yellow, and White as the main palette
- Keep the tone friendly, clean, and modern
- Avoid dense borders, tiny text, and enterprise dashboard styling on public-facing recruitment pages
- Use soft shadows sparingly
- Prefer rounded cards and clear separation
