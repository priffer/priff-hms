# KC Clean Trade Workforce Platform

## Product Positioning

KC Clean Trade Workforce Platform คือแพลตฟอร์มรับสมัครงานและใช้งานสำหรับพนักงานของนายจ้างรายเดียว

นี่ไม่ใช่ Job Marketplace.

KC Clean Trade is the only employer on the platform.

## Core Goals

1. หางาน
2. สมัครงาน
3. Employee Self Service
4. Employer Portal

## Core Message

> หางานใกล้บ้านคุณ

## User Understanding Rule

The user must understand the page in under 5 seconds.

Within the first screen, the user should immediately understand:

- this is a KC Clean Trade workforce platform
- jobs are near their home
- they can search quickly
- they can apply easily
- the platform is for one employer, not a marketplace

## Experience Principles

- Search first
- Mobile first
- Workforce first
- One employer only
- Fast decision making
- Minimal distraction
- Plain language
- Big touch targets

## Platform Boundaries

Do not position the product as:

- a LinkedIn-style professional network
- a JobsDB-style multi-company marketplace
- a content platform with blog/news
- a corporate company website with many navigation branches
- a SaaS startup dashboard
